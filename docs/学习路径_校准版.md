## 三、7 周路径

### 第 1 周｜P0 可讲性 + 项目卫生 + 投递启动
- **P0（最重要）**：读 `day21.py` 32-137 行 → 不看稿口述"三工具 + 数据流 + 评测数字"
- 项目卫生：密钥缺失即报错 + `.env.example` + `requirements.txt`；`query_regulation` 返回带来源；`query_dataset` 加 try/except + LIMIT；魔法数字抽常量
- 投递：A 层 15 家 + B 层 5 家（用巡检清单）
- ✅ 验收：口述 1 分钟版不看稿；投递记录 ≥20 行

### 第 2 周｜后端基础（JD 高频缺口）
- **FastAPI CRUD**：GET/POST/PUT/DELETE + **Pydantic 校验** + 参数化 SQL + 404/422 处理
- ➕ **结构化输出升级**：工具/接口返回用 **Pydantic / JSON Schema 校验**（企业要求"输出可控"）
- 给项目加 **CRUD 模块**（`monitoring_series` 可增删改查）+ `/health`
- **LlamaIndex**：跑通一个最小检索（半天）
- **FAISS**：概念 + 最小 demo（半天）
- ✅ 验收：Swagger 截图 + curl 跑通 CRUD；LlamaIndex/FAISS demo 各 1 个

### 第 3 周｜上下文工程 + 记忆 + 可观测性 + 安全（Agent 岗核心）
- **多轮对话**：`st.session_state` 存 messages 历史
- **上下文控制**：滑动窗口截断 + 摘要压缩 + 工具返回裁剪
- **长期记忆**：SQLite/Chroma 存历史问答，跨会话检索
- **可观测性**：工具调用日志（时间/工具名/入参/耗时/返回长度）
- **失败退出**：`max_iterations`、超时、工具异常统一返回
- **智能体安全**：工具参数校验 + 权限划分（写操作需确认）
- ✅ 验收：能多轮追问；日志可查；异常不崩

### 第 4 周｜RAG 评测深化（JD 明确"检索/生成/上下文"三维度）
- 测试集 12 → **30-50 题**（关键词区分度校验）
- ➕ **混合检索（向量 + 关键词）+ Rerank（BGE-Reranker）**：企业级 RAG 的标准动作，对比召回提升
- ➕ **RAGAS 指标概念**：faithfulness / answer relevancy / context precision（面试通用语言）
- **三维度评估**：① 检索命中率 ② 生成质量（人工评分或 LLM 裁判）③ 上下文使用（是否真用上检索内容）
- 结果落 `eval_result.md`：参数对比表 + 结论
- ✅ 验收：评测报告可复现；能讲"为什么 k 取最小够用"与"混合检索+Rerank 的收益"

### 第 5 周｜MCP + 工程化部署（运维岗卖点）
- **MCP**：概念（client/server/协议）→ 接通一个现成 MCP server → 把 `query_dataset` 包成 MCP server
- ➕ **LangSmith 追踪**：免费额度跑通一次，把"自己写日志"升级为行业通用可观测
- ➕ **OWASP LLM Top 10 概念 + 护栏思路**（并入智能体安全）
- ➕ **Dify / Coze 跑通一个工作流**（1 天，覆盖"AI 实施/交付"岗）
- **docker compose**（app + 数据卷）+ `.dockerignore` + `/health` 探活
- **GitHub Actions**：push → pytest → build → 部署
- 简单监控（Uptime Kuma 探活）
- ✅ 验收：compose 一键起；CI 通过；探活页面可见

### 第 6 周｜Workflow 编排 + HITL + 前端壳
- **LangGraph 显式状态图**：意图识别 → 检索 → 风险评估 → 报告；条件边 / 重试 / checkpoint
- **HITL 人工审批**：高风险建议需人工确认后再执行
- **Vibe Coding 生成简单前端**（用 AI 出页面，**不学 React**）
- ✅ 验收：状态图跑通 + HITL 演示 + 页面截图

### 第 7 周起｜面试冲刺（全程并行）
- 八股两套：Agent 向（工具注册/上下文/失败退出/记忆/可观测/评测）+ 运维向（Docker/compose/CI-CD/监控/排查）
- **模拟面试**（项目深挖 + 现场手写），被问倒的题当晚补
- 简历迭代：补 **AI Coding 工具**、评测数字、部署与 CI
- 密集投递：**Agent 方向优先**，每天 20-30 家

## 四、明确不做（JD 反向验证）

| 不做 | 理由 |
|---|---|
| Java / Spring AI | 只有 Java 存量系统岗需要 |
| 模型微调（LoRA/QLoRA） | 行业文章："企业对微调需求越来越少"；样本里多为算法岗 |
| 多模态 | 初级应用岗非必需，JD 点名再补 |
| 大模型算法 / 推理优化 / 量化 | 样本里全是**硕士**岗 |
| K8s 深入 | 初级运维岗不问；只到"能讲概念" |
| 多 Agent 协作 / Redis / Kafka | 只到"**能讲概念**"级，不投入实操 |
| React 系统学习 | 用 Vibe Coding 出页面即可 |
