# 公开学习路径对比与补充建议（2026-09-14）

> 来源：GitHub 上 4 个高质量公开路径（均为 2026 年活跃维护，覆盖企业级 Agent 场景）。
> 目的：用它们**校准**我们的《学习路径_校准版》，只采纳"初级岗能用上、企业真实需要"的部分。

---

## 一、四个公开路径概览

### ① [XingJi-love/ai-agents-from-zero](https://github.com/XingJi-love/ai-agents-from-zero)（中文，最贴国内 JD）
《AI 智能体实战速成指南：从零到企业级落地》· 2026 持续更新 · 附**面试题库（含大厂真题）**
- 明确**聚焦 Python + LangChain/LangGraph，"不走 Spring AI/Java 路线"**（与我们判断一致）
- 六大板块：大模型基础 → 低代码平台（Coze/Dify）+项目 → 核心框架（LangChain/LangGraph/**MCP/A2A**）→ **企业级 RAG/Agent 项目**（LangGraph RAG 工作流、MinerU/OCR 文档解析、**向量+稀疏+图 多路召回**、**HyDE/BGE-Rerank**、**RAGAS 评估**、NL2SQL、DeepAgents 多智能体、FastAPI SSE/WebSocket）→ 微调 → 大厂开发规范

### ② [NirDiamant/agents-towards-production](https://github.com/NirDiamant/agents-towards-production)（英文，最"生产级"）
**28 个生产级教程**，按能力域组织：
- 工具集成（**安全工具调用 + OAuth2 + HITL**）、数据处理、RAG（企业级 + **LMUnit 评估**）
- **记忆**（Redis 双记忆 / Mem0 混合向量+图 / Cognee 知识图谱）
- **部署**（Docker / AWS AgentCore / Ollama 本地部署）、**GPU 部署**（RunPod）
- **安全**（LlamaFirewall 输入输出护栏、**prompt injection 攻防与自动化安全测试**）
- 框架（LangGraph / FastAPI / MCP）、**Tracing（LangSmith）**、**Evaluation**、Streamlit UI

### ③ [h00w/agentic-ai](https://github.com/h00w/agentic-ai)（英文，最"体系化"）
**Agentic AI Academy：14 模块 + 按角色学习路径 + 48 案例评测基准**
模块：探索 → **Python** → LLM/Agent 基础 → **单 Agent 工程** → **Tools/APIs/MCP** → **RAG/知识/记忆** → 多智能体 → **Agent 评测** → **安全与合规** → **生产工程** → **可观测性与运维** → 治理/风险/扩展 → **企业架构** → 领导力
- 理念：*"capability 必须配 measurable reliability、bounded autonomy、explicit permissions、evaluation、observability、governance、safe failure"*
- 提供：**生产就绪检查清单**、风险登记册、治理清单、部署手册
- 学习路径：Complete Beginner 12–16 周 / Python Developer 8–10 周

### ④ [Skopaq-AI/awesome-ai-engineer](https://github.com/Skopaq-AI/awesome-ai-engineer)（英文，最"全景 + 项目多"）
**4 级职业路线 + 18 个生产项目**：
- L1 AI Engineer：LLM 基础、**结构化输出/受控解码**、RAG 管道、API + 流式
- L2 Senior：Agent 架构（ReAct/Plan-Execute/Code Agent）、**多智能体编排**、框架（LangGraph/CrewAI/PydanticAI/ADK）、**Prompt 优化（DSPy/TextGrad）**、实时语音
- L3 Platform：**MLOps/高吞吐服务（vLLM/TensorRT-LLM）**、**AI 网关与路由（LiteLLM/RouteLLM）**、记忆（Letta/Mem0/Zep）、**K8s+GPU**、可观测（LangSmith/Phoenix）、**协议（MCP/A2A/UCP）**
- L4 Architect：企业级多智能体、推理模型与测试时计算、上下文缓存经济性、**运行时护栏与安全（OWASP Top 10 for LLMs）**
- 项目示例：Ask-the-Web Agent、Agent RAG、MCP&A2A、Enterprise AI Gateway、Stateful Memory Agent、AI Guardrails Firewall、Incident Response ADK

## 二、对比结论：我们路径的定位

| 维度 | 我们（校准版） | 公开路径 | 判断 |
|---|---|---|---|
| 语言路线 | Python + LangChain/LangGraph | ①明确不走 Java；②③④也是 Python 主线 | ✅ 一致 |
| RAG | 全链路 + 12 题评测 → 深化到 30-50 题三维度 | ①多路召回+Rerank+RAGAS；②企业级+评估 | ⚠️ **需补"混合检索 + Rerank + RAGAS"** |
| Agent | 三工具 create_agent → 上下文/记忆/安全 → Workflow | ②③④都把 Agent 工程化拆很细 | ✅ 方向一致 |
| 评测 | 检索命中 + 生成质量 + 上下文使用 | ①RAGAS ②IntellAgent/LMUnit ③48 案例基准 ④RAGAS/DeepEval/Promptfoo | ⚠️ **了解 RAGAS 指标即可**（不必上框架） |
| 可观测 | 自己写工具调用日志 | ①LangSmith ②LangSmith ④LangSmith/Phoenix | ⚠️ **升级为 LangSmith 追踪（免费额度）** |
| 安全 | 工具权限/参数校验/输入校验 | ①②③④都是独立大模块（护栏/prompt injection/OWASP） | ⚠️ **补"OWASP LLM Top10 概念 + 护栏思路"** |
| 部署 | Docker + compose + CI + 探活 | ②Docker/AWS/Ollama/GPU ④K8s+GPU | ✅ 我们够用；K8s/GPU **不做** |
| 多智能体 | 只到"能讲概念" | ①DeepAgents ②A2A ③模块07 ④多项目 | ✅ 维持"概念级" |
| 微调 | 不做 | ①有专区 ②有教程 ④有 PEFT/Unsloth | ✅ **维持不做**（初级应用岗不需要） |
| 低代码平台 | 未涉及 | ①Coze/Dify 独立板块 + 项目 | ⚠️ **建议 1-2 天跑通一个 Dify 工作流**（覆盖"AI 实施/交付"岗） |
| 结构化输出 | 项目里已有"结构化报告" | ①结构化输出 ④受控解码/Instructor/Outlines | ⚠️ **升级为 Pydantic/JSON Schema 校验**（第 2 周顺带） |

## 三、采纳清单（只加 6 项，都在 1-2 天内可完成）

| # | 补充项 | 放在哪周 | 为什么（企业场景） | 来源 |
|---|---|---|---|---|
| 1 | **结构化输出用 Pydantic/JSON Schema 校验** | 第 2 周（做 FastAPI 时顺带） | 企业要求"输出可控"，也是接口层基本功 | ①④ |
| 2 | **混合检索（向量 + 关键词）+ Rerank（BGE-Reranker）** | 第 4 周（评测深化时一起做） | 企业级 RAG 的标准动作，显著提升召回 | ① |
| 3 | **RAGAS 指标概念**（faithfulness / answer relevancy / context precision） | 第 4 周 | 面试讲"怎么评 RAG"时的行业通用语言 | ①④ |
| 4 | **LangSmith 追踪**（免费额度跑通一次） | 第 5 周 | 把"自己写日志"升级为行业通用可观测 | ②④ |
| 5 | **OWASP LLM Top 10 概念 + 护栏思路** | 第 5 周（并入安全） | 安全是③的独立模块、④的 L4 内容；面试常问 | ③④ |
| 6 | **Dify / Coze 跑通一个工作流** | 第 5 周末或第 6 周（1 天） | 国内企业大量用低代码做交付；覆盖"AI 实施/交付"岗 | ① |

## 四、明确不采纳（这些是 Level 3-4 或算法/平台岗）

| 不学 | 为什么 |
|---|---|
| 微调（LoRA/QLoRA/DeepSpeed/Llama-Factory） | 初级应用岗不需要；行业文章称企业微调需求下降 |
| vLLM / SGLang / TensorRT-LLM / Triton | 推理服务/平台岗（多为资深或算法） |
| K8s + GPU 编排、KServe/KubeFlow | 同上；了解概念即可 |
| 多智能体深挖（DeepAgents/CrewAI/AutoGen/A2A 实操） | 维持"能讲概念" |
| DSPy / TextGrad / Prompt 编译器 | 研究/资深向 |
| 实时语音/多模态/边缘 AI | 与目标岗无关 |
| Neo4j 知识图谱 / GraphRAG | 加分项但投入大，秋招后再看 |

## 五、这 4 个仓库怎么用（省时间用法）

| 仓库 | 建议用法 |
|---|---|
| ① ai-agents-from-zero | **中文主参考**：RAG/Agent 章节 + **面试题库**（按 JD 能力域刷） |
| ② agents-towards-production | **专题查阅**：记忆/安全/评测/Tracing/部署，遇到哪个查哪个 |
| ③ h00w/agentic-ai | **对照清单**：用它的 14 模块 + 生产就绪清单做"自检表" |
| ④ awesome-ai-engineer | **全景地图**：知道 Level 3-4 有什么（现在不学，但要能说出名词） |

> ⚠️ 使用原则：**看它们的"清单和顺序"，不要照抄它们的项目量**。你只有 6-7 周、且要边投边学——**做完自己项目的升级 = 最好的学习**。
