## 一、目标与定位

**你的差异化**：遥感科班 + **能独立交付上线 AI 应用**（RAG + 多工具 Agent + 评测 + Docker 部署 + 公网可访问）

| 层级 | 岗位 | 你的匹配 | 动作 |
|---|---|---|---|
| 🅰️ | AI 测试/评测、AI 实施交付、IT 支持、数据处理、遥感/GIS 内业 | ✅ 现在就能投 | 每天投 10-15 家（兜底） |
| 🅱️ | **Agent/智能体方向 AI 应用开发（经验不限/应届/1年以内）** | ✅ 命中 5/6 要求 | 每天投 8-12 家（**主攻**） |
| 🅲 | AI 运维(AIOps)、Agent 后端、大模型算法 | ❌ 现在不匹配 | 2-6 周补完后端/部署再投 |

**时间预算**：每天 2 小时 × 6-7 周（**投递与手写全程并行，不是"学完再投"**）

---

## 二、每日固定动作（2 小时 + 投递）

```
① 手写 Python 3 题（30min，先写后对答案，昨天错的今天默写）   ← 唯一会直接淘汰你的项
② 主线任务（60min，按第 4 节当周表格）
③ 读代码写 3 条 review（20min，用 8 条检查清单）
④ 登记投递 + 笔记（10min）
投递：碎片时间 20-30 家（🅱️ 优先，🅰️ 兜底）
```

**每周固定**：周一/周四各 15 分钟**巡检 JD**（校招 + 社招）；周日**复盘投递数据**（哪类回复率高）

### 第 3 周｜上下文工程 + 记忆 + 可观测性 + 安全（Agent 岗核心）
| 项 | 内容 |
|---|---|
| 目标 | 从"单轮 demo"升级为"能多轮、能排查、能兜底"的 Agent |
| 任务 | ① **多轮对话**（`st.session_state` 存 messages）② **上下文控制**：滑动窗口截断 + 摘要压缩 + 工具返回裁剪 ③ **长期记忆**：SQLite/Chroma 存历史问答，跨会话检索 ④ **可观测性**：工具调用日志（时间/工具名/入参/耗时/返回长度）⑤ **失败退出**：`max_iterations`、超时、工具异常统一返回 ⑥ **安全**：工具参数校验 + 权限划分（写操作需确认） |
| 资源 | [LangGraph 持久化/记忆](https://langchain-ai.github.io/langgraph/concepts/persistence/)、[LangChain Messages](https://python.langchain.com/docs/concepts/messages/) |

## 六、明确不做（JD 与公开路径反向验证）

| 不做 | 理由 |
|---|---|
| Java / Spring AI | 只有 Java 存量系统岗需要 |
| 微调（LoRA/QLoRA/DeepSpeed/Llama-Factory） | 初级应用岗不需要；行业称企业微调需求下降 |
| vLLM / SGLang / TensorRT-LLM / Triton | 推理服务岗（资深/算法） |
| K8s + GPU 编排（KServe/KubeFlow） | 同上，只到"能讲概念" |
| 多智能体深挖（DeepAgents/CrewAI/AutoGen/A2A 实操） | 维持"概念级" |
| DSPy / TextGrad / Prompt 编译器 | 研究/资深向 |
| 实时语音 / 多模态 / 边缘 AI | 与目标岗无关 |
| Neo4j 知识图谱 / GraphRAG | 投入大，秋招后再看 |
| Redis / Kafka 实操 | 只到"能讲概念" |
