# BOSS 直聘打招呼话术（3 版 + 使用要点）

> 使用规则：每条**开头 2 秒内说清你是谁+你能给什么+链接**；首条别超 100 字（BOSS 有预览长度）；别发"在吗""你好"。
> 建议把简历 PDF、项目链接提前准备好，对方回复后立刻发：**简历文件 + 演示链接 + GitHub**。
> 如果对方已读 3-5 天没回复，可补一条（别重复发同样内容）。

## 投递节奏建议

- 每天目标：主动打招呼 30-50 家（深圳 AI 应用 + 遥感 + 测绘三类轮着投）
- 最佳打招呼时间：工作日 9:30-11:30 / 14:00-17:00
- 岗位要求写"1-3 年经验"的初级岗也可以投，你有一条手写的 0 年"可演示作品"链
- 回复率提升点：把打招呼里的链接**换成可点的小名片**（BOSS 支持发链接卡片），手机端更方便
