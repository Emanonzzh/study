# BOSS 直聘打招呼话术（2026-09-17 修订版）

> **本次修订的原因**：看实际投递记录发现两个问题
> ① 投 Python 岗时第一句说"我是 26 届**遥感**本科" → HR 第一眼判断"专业不对口"
> ② 43% 的投递是**算法岗**（大模型算法/机器学习/深度学习）→ 那些要模型训练经验+硕士，必被筛

---

## 一、第一句的公式（最重要）

```
您好，{届别}本科，{岗位方向}方向。{一句话亮点 + 可验证}。{到岗时间}，方便聊聊吗？
                  ↑
          ★ 这个词必须和岗位 JD 对齐
```

### 定位词对照表（**投什么岗用什么词**）

| 投的岗位 | 第一句用这个定位词 | 别说 |
|---|---|---|
| Python 开发 / 后端 | 26届本科，**Python 方向** | ❌ 遥感本科 |
| AI 应用 / Agent / 大模型**应用** | 26届本科，**AI 应用开发方向** | ❌ 遥感本科 |
| 数据开发 / 数据分析 | 26届本科，**Python + 数据方向** | ❌ 遥感本科 |
| 遥感 / GIS / 测绘行业 AI 岗 | **遥感专业** 26届本科，转 AI 应用开发 | —（这里突出遥感是对的） |

> **一句话原则**：**"遥感"只在投遥感/GIS/测绘岗时出现在第一句。**
> 投其他岗时，它放到第二句往后（或干脆不提）。

## 三、投前筛选：**看到这些词直接跳过**

| 岗位名里出现 | 为什么跳过 |
|---|---|
| **算法**（大模型算法、算法工程师、NLP算法、CV算法） | 要模型训练/微调经验 + 通常硕士 |
| **机器学习 / 深度学习** | 同上，要 PyTorch 训练项目 |
| **高性能计算** | 要 C++/CUDA/并行计算 |
| Java / Go / C++ 为主 | 你简历是 Python 方向 |
| 数据标注 / AI 训练师 | 不是开发岗 |

**优先投这些词**：`Python`、`AI 应用`、`大模型应用`、`数据开发`、`数据分析`、`后端`、`实施`（GIS 方向）

> ⚠️ 注意「大模型**算法**」和「大模型**应用**」—— 差两个字，要求天差地别。

## 四、已读不回 / 未读的跟进话术

**已读不回（隔 1–2 天补一条，换个角度）**
```
您好，之前给您发过消息。如果方便的话，我把项目 demo 直接发您看一眼？
（RAG + Agent 项目，公网可打开：http://47.76.101.97:8501）
```

**为什么这样发**：第一条讲"我有什么"，第二条给"一个能立刻点开的链接"——**降低 HR 的决策成本**。

**未读超过 24 小时** → 直接放弃这个岗，去投下一批（多半是僵尸岗）。
