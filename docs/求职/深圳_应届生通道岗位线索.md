## 一、为什么这条通道比 BOSS 直聘重要

| BOSS 直聘（社招） | 高校就业信息网（校招） |
|---|---|
| 默认筛"有经验" | **明确面向应届生**，不因你没经验筛掉 |
| 中小企业为主 | 国企 / 事业单位 / 设计院大量走这条路，**不上 BOSS** |
| 竞争的是社招人群 | 竞争的是同届应届生 |

**你手上有两张别人没有的牌**：
1. **桂工校友身份** → 母校就业网的岗位你能直接看/投
2. **26 届 + 择业期**（广东 2 年，部分口径 3 年）→ 很多单位仍按应届生接收

**时间点**：9–10 月是校招/补录窗口，现在打最值钱。

## 三、明天的核实动作（30 分钟，照着做）

1. **登录桂工就业网**（`glut.gxbys.com` 或学校就业系统），用校友身份搜：
   `深圳` + `GIS` / `遥感` / `空间数据` / `数据管理`
2. **逐个打开上表链接**，只确认两件事：
   - ① **招哪一届**（2026 届 / 2027 届 / 择业期内均可）
   - ② **要不要工作经验**
3. 对口的：直接投递 + **打电话问 HR**：*"我是 2026 届毕业生，在择业期内，可以报考这个岗位吗？"*
4. 结果记进 `投递记录表.csv`（`匹配层级` 标 A / B）

**⚠️ 不要自己假设届别要求** —— 校招通常"毕业前一年秋招"，现在（2026 年 9 月）发布的"2026 年校园招聘"**很可能是招 2027 届**。但国企/事业单位对择业期内未就业毕业生常有放宽 → **必须问 HR**。
