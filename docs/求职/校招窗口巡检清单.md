# 校招窗口巡检清单（择业期内可用）

> 你的身份：**2026 年 6 月毕业，仍在择业期内（2 年，至 2028.06；广东可能放宽到 3 年）**
> → 可投标注"**2026届 / 2027届 / 应届生 / 择业期内未就业毕业生 / 毕业两年内**"的岗位。
> ⚠️ 校招是**窗口期**（报名常常只有 7-15 天），所以重点不是"要名单"，而是**每周固定巡检**。

## 二、目标单位（对口，值得长期盯）

**测绘/自然资源系统（最对口）**
- 深圳市规划和自然资源调查测绘中心（2026 公告已过期 → 盯下一次）
- 深圳市勘察研究院、深圳市工勘岩土集团
- 广东省测绘院 / 广东省国土资源测绘院、广州市城市规划勘测设计研究院
- 东莞市地理信息与规划编制研究中心、东莞自然资源系统下属单位

**国企信息化/技术岗（计算机类可投）**
- 东莞轨道公交集团（清分系统技术岗、自动化技术岗，2026/2027届都收）
- 深圳地铁、广州地铁（信息化/自动化岗）
- 南方电网 / 广东电网（信息化、数字化岗）
- 运营商（移动/电信/联通）广东/深圳/东莞分公司（IT 开发、数据岗）
- 地方国企数字化部门（水务、交通、城建集团）

**AI 应用 / 软件开发（校招补录/往届友好）**
- 中小 AI 应用公司、地理信息软件公司（超图/中地数码/苍穹等分公司）
- 有"2026届补录""毕业两年内"字样的岗位

## 三、投递动作（30 分钟能做完）

1. **注册 3 个平台**：ds.ncss.cn（24365）、91wllm、应届生求职网 → 完善在线简历 + 上传 PDF 版简历
2. **按专业筛选**：遥感/测绘/地理信息/计算机 → 收藏 10 家目标单位官网"校园招聘"页
3. **建一张表**（公司/岗位/截止日期/要求毕业年份/状态），每周更新
4. **校招与社招并行投**：校招流程慢（测评→笔试→面试，2-6 周），社招（BOSS）继续天天投

**📌 本次巡检结论（重要）**
1. **AI/Agent 校招主力是"2027届 + 硕士"**（睿魔的 VLA/VLM、商汤"无限原力"都是）→ 26 届本科在这条线上机会很少
2. 26 届本科可投的校招，主要是三类：
   - **国企/事业单位技术岗**（测绘/自然资源/交通/电网/运营商的信息化、数据处理岗）← 你专业对口，重点
   - **"校园招聘补录专场"**（关键词：补录、专场、未就业毕业生）
   - **地方国企数字化岗**（东莞/深圳/广州）
3. **Agent/AI 应用方向 → 以社招为主**（BOSS 搜"AI应用开发 1年以内/经验不限""AI实施交付"），校招只当补充
4. 公告有效期差异很大（7 天 ~ 3 个月都有），所以**每周巡检两次**是必要的

## 六、避坑

- 任何以"培训费/押金/保证金"为由收费的 = 诈骗，直接举报（平台上也有同样的风险提示）
- 公告里的"毕业时间要求"必须逐条核对（写 2027 届的别投，写 2026 届/两年内的可以）
- 国企多有**笔试**（行测/专业），提前准备（可刷行测题库 + 专业知识复习）
- 招聘公告集中在**工作日**发布，周一、周四巡检最有效
