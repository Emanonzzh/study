## 阶段 2.5 · 投前 10 秒自检（**别省这一步**）

> 教训来源：2026-09-16 投了 6–15 家、简历阶段全被拒。复盘发现至少有一个岗位
> 标题是"AI 应用开发**助理**"，标签却要"**架构设计经验 / 团队管理经验**"，
> 公司是**橡胶塑料贸易**、要 Python/JS/CSS/C# 全栈 → **需求本身混乱，不该投**。
> 投这种岗 = 浪费打招呼额度 + 打击自己的信心。

| 扫什么 | 出现这个就跳过 |
|---|---|
| ① 公司行业 vs 岗位 | 贸易/制造/传统行业招 AI 开发（规模又小）→ 大概率没技术团队 |
| ② **经验要求** | 写"1–3 年""3 年以上" → 你会被**筛选条件**筛掉，不是能力问题 |
| ③ **专业要求** | 明确写"计算机/软件工程/人工智能"且**没有"等/理工科/不限"** → 遥感会被系统过滤 |
| ④ 要求"精通 Python+JS+C#/架构设计" | 万能岗 = 低薪招资深 |
| ⑤ 加分项比硬要求还长 | 需求不清，大概率是"收简历池" |

**筛完再投**：把每天的打招呼额度（BOSS 有上限）花在**经验不限 + 专业含"等/理工科"** 的岗位上。

**优先投这类**：
- 写"**应届生 / 经验不限**"，且要求里提到 **项目经验** 的（这条你强）
- 要求里有 **Python / LangChain / RAG / Agent / LLM** 关键词的
- 公司是**软件/互联网/人工智能**行业的中小公司

## 阶段 2.6 · 只跟「活人 HR」打招呼（**回复率的关键**）

> 教训来源：2026-09-16 复盘发现 6–15 家投递里，大部分是**未读**。
> **未读 ≠ 被拒** —— 未读多半说明这是个**僵尸岗**（HR 早不招了、岗位没下架），
> 你敲的是没人的门。**再改简历也没用。**

| 看哪里 | 只选这些 |
|---|---|
| **HR 活跃状态** | ⭐ **刚刚活跃 / 今日活跃**（3 日内次之）→ 2 周内活跃的直接跳过 |
| **岗位标签** | ⭐ 带「**急招**」的 → HR 会主动看消息 |
| **发布/刷新时间** | 越新越好；挂了半年还在的多半是僵尸岗 |

**硬规矩**：
- 一条招呼发出 **24 小时未读 → 直接放弃这个岗**，不要再等、不要补发
- 别盯着"等回复"，**同时继续投下一批**（等回复会让你一天只投 3 家）

## 为什么是"15 家"而不是"投一家等一家"

按行业经验，BOSS 上的**有效回复率大约 5%–15%**。也就是说：
- 投 15 家 → 大约 1~2 个回复
- 投 50 家 → 大约 3~7 个回复，才可能约到 1~2 个面试

**投递是个概率游戏，量不到位，再多准备也没用。** 你的材料已经比大多数应届生强（可演示 + 3 个硬指标 + 完整文档），现在缺的只是**量**。
