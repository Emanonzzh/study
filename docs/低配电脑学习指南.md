# 低配电脑 · 学习/求职怎么继续（不装 Docker / MySQL / GPU 也能做）

> 场景：白天在另一台配置较低的电脑上继续学习，这台机没有 Docker、没有 MySQL、可能没独显。
> 原则：**低配机只做"读、写、背"，不做"跑重型环境"**。重型环境（MySQL/torch/Docker）留在主力机。

---

## 一、能不能做，一张表说清

| 内容 | 需要什么 | 低配机能否 |
|---|---|---|
| 读文档（学习路径 / 口述稿 / 项目框架 / 评测） | 浏览器或任意编辑器 | ✅ 首选 |
| 手写练习（Python 基础 / SQL） | 纸笔，或 Python 解释器 | ✅ |
| SQL 入门练习 | Python 自带 `sqlite3`，零安装 | ✅ |
| 阅读代码（`agent_lab/`、`day21.py` 等） | 编辑器即可 | ✅ |
| 口述练习 + 30 问自测 | 只要人 + 文档 | ✅ |
| 跑 RS 项目的 RAG/Agent（调 qwen） | Python + 依赖 + 联网 + API key | ⚠️ 能跑但慢，key 别乱传 |
| 跑 `agent_lab/tools.py`（量价分解） | **MySQL**（102,287 行 orders 表） | ❌ 别在这台跑 |
| 跑 chroma / BGE 模型 / torch | ≥8G 内存或 GPU | ❌ 别在这台跑 |

## 二、低配机最小环境（10 分钟，可选）

如果只是想读文档 + 手写练习，**什么都不用装**。如果要跑轻量 Python：

```powershell
# 1) 装 Python 3.12（官网下载，勾选 Add to PATH）
# 2) 拉代码（SSH 或 HTTPS 二选一）
git clone git@github.com:Emanonzzh/study.git
# 3) 无需 Docker / MySQL / GPU / conda
```

## 三、白天在低配机上最该做的三件事（按性价比排序）

1. **口述 + 自测**（求职最高优先级）
   - `docs/求职/项目二_技术栈口述稿与内化自测.md` 的 30 问，先自己答，答不上来就打标记
   - `docs/求职/销售经营分析Agent_项目框架.md` 的"七个为什么"，逐条能不看稿讲出来
   - `项目口述稿_遥感监测智能助手.md` 的一分钟版背熟

2. **手写练习**（补编程基础）
   - `手写练习_题单与答案.md`：用纸或记事本写，写完再对答案
   - `SQL增删改查入门.md`：用 Python `sqlite3` 在低配机就能练，无需装 MySQL

3. **读代码写注释**（吃透 Agent）
   - 打开 `agent_lab/tools.py`、`p1_react.py`，逐行写"这行在干嘛"
   - 重点搞懂三件事：**量价三因子分解为什么能精确加总、ReAct 循环的停止条件有哪几个、错误怎么回传给模型**

## 四、明确不要在低配机做的事

- ❌ 装 Docker / MySQL（重、慢、没必要）
- ❌ 跑 `sentence-transformers` / `build_knowledge_base.py`（BGE 模型 + torch 吃内存）
- ❌ 跑 `p1_react.py`（需要 MySQL + DeepSeek key，key 在主力机 `.env` 里，**别传到低配机**）

## 五、密钥纪律（跨机器尤其重要）

- `.env`、`my-client.ini`、API key **永不入 Git**（本仓库 `.gitignore` 已忽略）
- 低配机若临时要调 LLM，用你自己的 key 通过环境变量传，用完删，不要写进文件

## 六、跨机器同步的工作流

主力机（今晚）：`git commit -am "..."` → `git push`
低配机（白天）：`git pull` → 学习/写 → 有产出就 `git commit -am "..."` → `git push`
晚上回主力机：`git pull` 接着做

> 两处代码仓库：学习文档在 `Emanonzzh/study`；销售项目在 `ai-commerce-intelligence-platform`（第三个开源仓库的克隆，`agent_lab/` 已同步一份快照到本仓库）。
