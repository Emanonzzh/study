## 第 1 组题单（列表索引 / 切片 / 循环 / 四舍五入）

1. **`recent_rate(values)`**：输入形变值列表（按时间从早到晚），返回"最近 3 期的平均月增量"，保留 1 位小数；不足 4 个值返回 `None`。
   测试：`[2.1, 3.5, 5.0, 7.2, 9.8]` → `2.1`

2. **`max_deform(data)`**：输入 `{"川西": [98, 132, 80], "洱海": [55, 60, 52], "滇池": [88, 91, 90]}`，返回**沉降最大值最大的区域名**和那个值（返回 `(区域名, 最大值)`）。不许用内置 `max()`。

3. **`longest_growth(values)`**：输入形变列表，返回**连续增长的最长段长度**（例如 `[1,2,3,2,4,5,6]` → `3`）。不许用内置函数。

## 参考答案（写完再往下看）

### 1. recent_rate —— 两种写法

**写法 A（最短，推荐掌握）**
```python
def recent_rate(values):
    if len(values) < 4:          # 不足 4 个值，算不出 3 期增量
        return None
    total = values[-1] - values[-4]   # 倒数第1个 - 倒数第4个 = 3 段增量之和
    return round(total / 3, 1)        # 3 段求平均，保留 1 位小数
```
心法：**负索引 `-1` 是最后一个，`-4` 是倒数第四个**；两者相减就是"最近 3 期的总增量"。

**写法 B（循环版，贴合"逐段累加"的直觉）**
```python
def recent_rate(values):
    if len(values) < 4:
        return None
    total = 0
    for i in range(len(values) - 4, len(values) - 1):   # i 从倒数第4个走到倒数第2个
        total += values[i + 1] - values[i]              # 相邻两期相减
    return round(total / 3, 1)
```
心法：**想不清负索引就用正索引**（`len(values) - k`）。

**原答案的 3 个 bug（对照记牢）**
| bug | 原因 | 正确做法 |
|---|---|---|
| `range(-4, values)` | `range()` 第二个参数必须是整数，传了列表 | `range(len(values)-4, len(values)-1)` |
| `values[-i+1] - values[-i]` | 负索引方向搞反，`i=-4` 时成 `values[5]` 越界 | 相邻两期：`values[i+1] - values[i]` 或首尾差 `values[-1]-values[-4]` |
| 直接 `total / 3` | 忘了题目要求保留 1 位小数 | `round(total / 3, 1)` |

### 2. max_deform
```python
def max_deform(data):
    best_region = None
    best_value = None
    for region in data:                 # 遍历字典的 key
        values = data[region]
        local_max = values[0]
        for v in values:
            if v > local_max:           # 不用内置 max，自己比较
                local_max = v
        if best_value is None or local_max > best_value:
            best_value = local_max
            best_region = region
    return best_region, best_value
```
要点：**双层循环**；外层遍区域，内层找该区域最大值；再用一个"当前最好"变量做擂台。

### 3. longest_growth
```python
def longest_growth(values):
    if len(values) == 0:
        return 0
    longest = 1
    current = 1
    for i in range(1, len(values)):
        if values[i] > values[i - 1]:
            current += 1               # 继续增长
            if current > longest:
                longest = current
        else:
            current = 1                # 断了，重新计数
    return longest
```
要点：**擂台 + 计数器**；断了要把 `current` 重置为 1。
