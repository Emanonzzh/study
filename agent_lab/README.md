# agent_lab —— 手写 Agent 代码（快照）

这是我**不依赖任何 Agent 框架**手写的 Agent 实验代码，属于销售经营分析项目的一部分：

| 文件 | 内容 | 行数 |
|---|---|---|
| `tools.py` | 4 个纯函数工具：指标查询 / 月度趋势 / 维度排名 / **量价三因子分解**（含精确加总断言） | 367 |
| `p1_react.py` | 手写 ReAct 循环：步数上限 / token 预算 / 重复动作检测 / observation 截断 / 错误回传 / 全轨迹 | 296 |
| `p1_stress.py` | 6 场景故障注入压测（超纲 / 非法参数 / DB 超时 / 模糊提问 / 跨维度 / 重度取数） | 118 |

## ⚠️ 运行前提

- 需要 **MySQL**（`orders` 表 102,287 行）+ **DeepSeek key**（`.env`）
- **低配机 / 无 MySQL 时只读代码，不要运行** —— 读代码 + 写注释同样能学会

## 本目录定位

- 这是**可读快照**，方便在别的电脑上 `git pull` 后阅读学习
- **活的版本**在 `ai-commerce-intelligence-platform/agent_lab/`（另一个仓库），会继续迭代
- 两处如有差异，以那边为准

## 学习重点（面试要能讲）

1. **量价三因子分解**为什么能精确加总（`ΔR = 量效应 + 价效应 + 交互项`，断言闭合 0.0）
2. **ReAct 循环**的停止条件有哪几个、为什么"重复动作检测"不能只看参数相同（我踩过的坑）
3. **错误回传**：工具报错为什么当 observation 回传给模型，而不是直接抛异常
