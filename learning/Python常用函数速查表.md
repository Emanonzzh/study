## ① 万能基础（几乎每道题都用）

| 函数 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| `len(x)` | 长度 | `len([1,2,3])` | `3` | ☐ ☐ ☐ |
| `sum(x)` | 求和 | `sum([1,2,3])` | `6` | ☐ ☐ ☐ |
| `max(x)` / `min(x)` | 最大/最小 | `max([1,5,3])` | `5` | ☐ ☐ ☐ |
| `abs(x)` | 绝对值 | `abs(-7)` | `7` | ☐ ☐ ☐ |
| `round(x, n)` | 四舍五入 | `round(3.567, 1)` | `3.6` | ☐ ☐ ☐ |
| `sorted(x)` | 排序（返回新列表） | `sorted([3,1,2])` | `[1,2,3]` | ☐ ☐ ☐ |
| `sorted(x, reverse=True)` | 倒序 | `sorted([1,3,2], reverse=True)` | `[3,2,1]` | ☐ ☐ ☐ |
| `reversed(x)` | 反转（返回迭代器） | `list(reversed([1,2,3]))` | `[3,2,1]` | ☐ ☐ ☐ |
| `range(n)` | 数字序列 | `list(range(3))` | `[0,1,2]` | ☐ ☐ ☐ |
| `range(a,b)` | 从 a 到 b-1 | `list(range(2,5))` | `[2,3,4]` | ☐ ☐ ☐ |
| `enumerate(x)` | 同时拿下标和值 | `list(enumerate(['a','b']))` | `[(0,'a'),(1,'b')]` | ☐ ☐ ☐ |
| `enumerate(x, start=1)` | 下标从 1 开始 | `list(enumerate(['a'], start=1))` | `[(1,'a')]` | ☐ ☐ ☐ |
| `zip(a, b)` | 两个列表配对 | `list(zip([1,2],['x','y']))` | `[(1,'x'),(2,'y')]` | ☐ ☐ ☐ |
| `x in y` | 判断存在 | `3 in [1,2,3]` | `True` | ☐ ☐ ☐ |

> ⚠️ **`sorted(x)` vs `x.sort()`**：`sorted` 返回**新列表**；`x.sort()` **原地排序，返回 `None`**。
> 写错成 `return nums.sort()` → 返回 None，答案直接错。

|---|---|---|---|---|
| `.append(x)` | 末尾加一个 | `a=[1]; a.append(2)` | `a=[1,2]` | ☐ ☐ ☐ |

| `a[::-1]` | 反转 | `[1,2,3][::-1]` | `[3,2,1]` | ☐ ☐ ☐ |

## ③ 字典 dict ★★★（统计频次必用，**你最需要练的**）

| 写法 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| `d[k] = v` | 存 | `d={}; d['a']=1` | `d={'a':1}` | ☐ ☐ ☐ |
| `d[k]` | 取（**键不存在会报错**） | `{'a':1}['a']` | `1` | ☐ ☐ ☐ |
| **`d.get(k, 0)`** | 取，不存在返回 0 ★ | `{'a':1}.get('b', 0)` | `0` | ☐ ☐ ☐ |
| `k in d` | 键在不在 | `'a' in {'a':1}` | `True` | ☐ ☐ ☐ |
| `d.keys()` | 所有键 | `list({'a':1}.keys())` | `['a']` | ☐ ☐ ☐ |
| `d.values()` | 所有值 | `list({'a':1}.values())` | `[1]` | ☐ ☐ ☐ |
| `d.items()` | 键值对 | `list({'a':1}.items())` | `[('a',1)]` | ☐ ☐ ☐ |
| `d.pop(k, 0)` | 弹出键（给默认值防报错） | `{'a':1}.pop('b', 0)` | `0` | ☐ ☐ ☐ |

### ★ 统计频次的标准写法（背下来）

```python
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
```

**同一模式还能用在**：统计数字出现次数、统计单词频率、分组计数……
**这是刷题里复用率最高的一段代码。**

## ④ 集合 set（去重 + 判断存在）

| 写法 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| `set(x)` | 去重 | `set([1,1,2])` | `{1,2}` | ☐ ☐ ☐ |
| `.add(x)` | 加元素 | `s={1}; s.add(2)` | `s={1,2}` | ☐ ☐ ☐ |
| `.discard(x)` | 删（不存在也不报错） | `{1,2}.discard(1)` | `{2}` | ☐ ☐ ☐ |
| `x in s` | 判断存在 | `2 in {1,2}` | `True` | ☐ ☐ ☐ |
| `a & b` | 交集 | `{1,2} & {2,3}` | `{2}` | ☐ ☐ ☐ |
| `a \| b` | 并集 | `{1,2} \| {2,3}` | `{1,2,3}` | ☐ ☐ ☐ |
| `a - b` | 差集 | `{1,2,3} - {2}` | `{1,3}` | ☐ ☐ ☐ |

### ★ 常用组合

```python
sorted(set(nums))                 # 去重 + 排序
len(set(nums)) != len(nums)       # 判断有没有重复（217 题）
```

## ⑤ 字符串 str

| 方法 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| **`.split(sep)`** | 切成列表 ★ | `"a-b-c".split("-")` | `['a','b','c']` | ☐ ☐ ☐ |
| **`sep.join(list)`** | 拼成字符串 ★ | `"-".join(['a','b'])` | `'a-b'` | ☐ ☐ ☐ |
| `.strip()` | 去首尾空白 | `"  a  ".strip()` | `'a'` | ☐ ☐ ☐ |
| `.lower()` / `.upper()` | 转小写/大写 | `"AbC".lower()` | `'abc'` | ☐ ☐ ☐ |
| `.replace(a, b)` | 替换 | `"aaa".replace('a','b')` | `'bbb'` | ☐ ☐ ☐ |
| `.startswith(s)` | 是否以 s 开头 | `"abc".startswith('a')` | `True` | ☐ ☐ ☐ |
| `.isdigit()` | 是否全是数字 | `"123".isdigit()` | `True` | ☐ ☐ ☐ |
| `.isalpha()` | 是否全是字母 | `"abc".isalpha()` | `True` | ☐ ☐ ☐ |
| `.count(c)` | c 出现几次 | `"aab".count('a')` | `2` | ☐ ☐ ☐ |
| `.find(c)` | c 的下标（没有→-1） | `"abc".find('b')` | `1` | ☐ ☐ ☐ |
| `sorted("cba")` | 字符串排序 | `sorted("cba")` | `['a','b','c']` | ☐ ☐ ☐ |

> ⚠️ **`join` 的方向最容易记反**：是 `"分隔符".join(列表)`，**不是** `列表.join("分隔符")`。

## ⑥ 类型转换

| 函数 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| `int(s)` | 转整数 | `int("42")` | `42` | ☐ ☐ ☐ |
| `str(x)` | 转字符串 | `str(42)` | `'42'` | ☐ ☐ ☐ |
| `float(s)` | 转小数 | `float("3.14")` | `3.14` | ☐ ☐ ☐ |

## ⑦ 列表推导式（读别人代码必会）

| 写法 | 作用 | 例子 | 结果 | 掌握 |
|---|---|---|---|---|
| `[f(x) for x in a]` | 每个元素变换 | `[x*2 for x in [1,2]]` | `[2,4]` | ☐ ☐ ☐ |
| `[x for x in a if 条件]` | 过滤 | `[x for x in [1,2,3] if x>1]` | `[2,3]` | ☐ ☐ ☐ |
| `[x for x in a if x%2==0]` | 偶数 | `[x for x in [1,2,3,4] if x%2==0]` | `[2,4]` | ☐ ☐ ☐ |
| `[f(x) for x in a if 条件]` | 变换+过滤 | `[x*2 for x in [1,2,3] if x>1]` | `[4,6]` | ☐ ☐ ☐ |

**读法**：`[要什么  for 从哪来  if 什么条件]`

## ⑨ 怎么自学不认识的函数 —— **`help()`**

```python
help(sorted)
```

输出：
```
sorted(iterable, /, *, key=None, reverse=False)
       ↑              ↑            ↑
    必填的序列      可选参数      可选参数（含默认值）
```

**从这一行就能看出：参数有哪些、哪些必填、默认值是多少。**

> 以后遇到不认识的函数/参数，**先 `help(函数名)`，比问人快十倍。**
