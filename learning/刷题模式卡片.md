# 刷题模式卡片（记模式，不记代码）

> **为什么要有这个文件**
> 做完题记不住，不是记性差 —— 是因为在"记代码"，而**面试不考背题**。
> 面试给你一道**没见过的新题**，考的是"看到特征 → 识别模式 → 写出来"。
> 模式只有 20–30 个。**记住模式，不是记住题。**
>
> **用法**：每做完一题填一行；然后按"间隔重复"重做：当天 → 次日 → 3 天后 → 7 天后。
> **旧题重做比做新题重要。**

## 卡片

### 217. 存在重复元素（Contains Duplicate）

- **看到什么特征**：判断"有没有出现过 / 有没有重复"
- **用什么模式**：**哈希集合（set）**
- **代码骨架**：
  ```python
  seen = set()
  for x in nums:
      if x in seen:
          return True
      seen.add(x)
  return False
  ```
- **我卡在哪**：
- **复杂度**：时间 O(n)，空间 O(n)
- **同类题**：349 两个数组的交集、1 两数之和（哈希表版）

---

### 242. 有效的字母异位词（Valid Anagram）

- **看到什么特征**：比较两个东西的**组成**是否相同（**顺序无关**）
- **用什么模式**：**哈希计数（字典统计频次）**
- **代码骨架**（两种，都记下来）：
  ```python
  # 写法 A：用 Counter（简洁，面试可写）
  from collections import Counter
  return Counter(s) == Counter(t)

  # 写法 B：手写字典计数（面试官想看你会不会）
  counts = {}
  for ch in s:
      counts[ch] = counts.get(ch, 0) + 1
  for ch in t:
      if ch not in counts:
          return False
      counts[ch] -= 1
      if counts[ch] == 0:
          del counts[ch]
  return not counts          # 都消掉才算异位词
  ```
- **我卡在哪**：
- **复杂度**：时间 O(n)，空间 O(k)（k = 字符集大小）
- **同类题**：383 赎金信、49 字母异位词分组

### 121. 买卖股票的最佳时机（Best Time to Buy and Sell Stock）

- **看到什么特征**：找**最大差值**，且**顺序不能反**（先买后卖）
- **用什么模式**：**一次遍历 + 维护"到目前为止的最小值"**
- **代码骨架**：
  ```python
  min_price = float('inf')
  best = 0
  for p in prices:
      min_price = min(min_price, p)      # 先更新历史最低
      best = max(best, p - min_price)    # 再算今天卖的收益
  return best
  ```
- **我卡在哪**：容易一上来写双重循环（O(n²)）→ 超时
- **复杂度**：时间 O(n)，空间 O(1)
- **同类题**：53 最大子数组和（同款"边走边维护状态"）

## 模式索引（做题时先来这里找）

| 看到什么特征 | 想到什么模式 |
|---|---|
| 判断有没有出现过 / 去重 | **哈希集合 set** |
| 统计频次 / 比较组成 | **哈希计数 dict** |
| 找两数之和 / 需要"配对的另一个" | **哈希表：边遍历边存，查 complement** |
| 有序数组找两数 / 去重 | **双指针** |
| 找最长/最短的连续子串 | **滑动窗口** |
| 找最大差值 / 最大子数组 | **一次遍历维护状态（min/max/cur）** |
| 括号匹配 / 最近的未匹配 | **栈** |
| 层序 / 最短路径 | **BFS + 队列** |
| 树 / 分治 | **递归** |
| 有序数组查找 | **二分** |

> **用法**：拿到新题先扫这张表。**能对上特征，就知道用什么方法** —— 这就是"会做题"的本质。

## 每天的最小任务量

```
新题 2 道   +   旧题重做 1 道（从间隔重复表里挑）
```

**别贪多。** 2 新 + 1 旧，坚持 2 周，你会明显感觉到"看到题知道该干什么了"——**那一刻就是"入门"了**。
